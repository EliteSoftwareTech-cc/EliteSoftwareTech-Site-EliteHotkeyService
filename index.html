Low-Level Global Hotkey Interception & Cross-Session SCM Service

Built in native Win32 C++17, EliteHotkeyService pairs a lightweight WH_KEYBOARD_LL key-hook engine (elite-hotkey.exe) with a Session 0 Windows Service (elite-hotkey-svc.exe) and a classic Windows Vista-styled configuration dialog. Designed to keep global shortcuts such as WIN + R working reliably even in custom-shell or explorer-less Windows environments.

Vista-Styled Win32 Configuration Interface NATIVE WIN32 GUI

Configuration dialog launched via elite-hotkey.exe /config or hotkeys — featuring live shortcut recording, instant auto-save to C:\ProgramData\EliteSoftware\Hotkeys\config.ini, and SCM service controls.

Core Engine & Privilege Handoff C++17 • WH_KEYBOARD_LL

  • Low-level keyboard hook supporting multi-modifier combinations (WIN, CTRL, ALT, SHIFT) and special/function keys.
  • Direct target execution via CreateProcessW & SearchPathW (System32\run.exe) without relying on explorer.exe.
  • Automatic modifier key-up cleanup before spawning actions to prevent stuck Win/Ctrl/Alt keys.
  • Privilege-ranked single-instance handoff (SYSTEM → Elevated Admin → Standard User) and instant live reload via Global\EliteHotkey_Reload_Event.

Windows Service & CLI Suite ELITEBEGINNINGSOFFICIAL

  • elite-hotkey-svc.exe registers EliteHotkey_Service under NT AUTHORITY\SYSTEM and monitors active console sessions via WTSGetActiveConsoleSessionId.
  • hotkeys.exe / hotkeys.cmd provide quick CLI aliases: hotkeys (Config UI), hotkeys -start, hotkeys -stop, and hotkeys -restart.
  • Scripts/Setup-EliteHotkeyService.ps1 stages binaries, sets BUILTIN\Users modify ACLs on config.ini, installs the service, and configures scheduled tasks.
  • Built cleanly via CMake (Visual Studio 16 2019 x64) using build.ps1.
