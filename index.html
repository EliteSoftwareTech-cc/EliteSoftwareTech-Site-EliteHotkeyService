Custom Global Hotkeys & Native Windows Key Overrides

EliteHotkey Service enables overriding built-in Windows shortcuts (including Win key combinations) and binding custom system actions across user and SYSTEM contexts. This portal houses both the Current Named-Pipe / Registry Edition (Elite_Hot-Key_Service) and the v1 / Legacy Edition (EliteHotkeyService v1.1.1.0).

Current Edition: Elite_Hot-Key_Service CURRENT / PIPE V5

  • IPC & Registry Persistence: Communicates between App.cpp and Service.cpp over named pipe \\.\pipe\EliteHotkeyServicePipeV5, storing entries under HKLM\SOFTWARE\EliteSoftware\Hotkeys\ServiceV5.
  • Native & Win-Key Overrides: Supports overrideNative flags, fullscreen app detection/blocking (blockFullscreen), and toggling entries individually.
  • Flexible Execution: Launch commands directly or via shell (runAsCommand), with optional runAsSystem delegation via the Windows Service.
  • Visual Config UI: Built with native Win32 Common Controls and persistent ListView column widths.

v1 / Legacy Edition: EliteHotkeyService v1 / LEGACY (v1.1.1.0)

  • INI & SCM Architecture: Uses C:\ProgramData\EliteSoftware\Hotkeys\config.ini, WH_KEYBOARD_LL hooking, and EliteHotkey_Service in Session 0.
  • CLI & Deployment Wrappers: Includes elite-hotkey.exe (/config, /daemon, /init), elite-hotkey-svc.exe, hotkeys.exe, and Setup-EliteHotkeyService.ps1.
  • Instant Auto-Save: Persists mappings immediately and triggers Global\EliteHotkey_Reload_Event.
  • Preserved Release: Full compiled binaries & installer scripts archived in v1.1.1.0.
